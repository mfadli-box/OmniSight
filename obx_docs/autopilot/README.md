## Cara Pakai Singkat

1. Isi spesifikasi modul berdasarkan schema di module_spec_schema.md.
2. Jalankan implementasi mengikuti urutan pada ai_runbook.md.
3. Validasi output menggunakan checklist pada definition_of_done.md.

## Prinsip

- Satu sumber kebenaran spesifikasi per modul.
- Perubahan kecil dan terukur.
- Verifikasi wajib sebelum status selesai.

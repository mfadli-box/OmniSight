# SP00 - Guest Auth Flow

## Ringkasan

- Route: /rest/guest/SP00
- Tujuan: daftar company HRIS, login, logout
- Handler utama: ListHrisCompany, Login, Logout

## Technical Notes

- Endpoint guest tidak memakai USLoad
- Login menghasilkan token session untuk dipakai di /rest/pages
- Logout mencabut session aktif

## Endpoint

- GET /rest/guest/SP00
- POST /rest/guest/SP00
- DELETE /rest/pages/SP00

- [ ] HRIS company list tampil

# SP02 - Change Password

## Ringkasan

- Route: /rest/pages/SP02
- Tujuan: ubah password user aktif

## Technical Notes

- Endpoint update memakai USAuth/USLoad context
- Request body memuat password lama dan baru
- Response sukses mengembalikan pesan perubahan password

## Endpoint

- PUT /rest/pages/SP02

## Checklist

- [ ] Password validation aktif
- [ ] Response 200 saat sukses

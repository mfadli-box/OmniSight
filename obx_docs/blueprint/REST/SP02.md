# SP02 - Change Password API

## Ringkasan

- Route: /rest/pages/SP02
- Tujuan: mengganti password user yang sedang login

## Technical Notes

- Scope endpoint: auth user (USAuth)
- User ID diambil dari context session middleware
- Body wajib memuat current_password dan new_password
- Error validasi dikirim melalui mechanic.ValidationError

## Endpoint

- PUT /rest/pages/SP02

## Checklist Sinkronisasi

- [x] Validasi current_password dan new_password aktif
- [x] Response sukses status 200 dengan message
- [x] Unauthorized ditangani saat context user tidak tersedia

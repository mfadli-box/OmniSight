# SM03 - Company Management API

## Ringkasan

- Prefix route: /rest/pages/SM03
- Scope: admin only (USAuth + USLock)
- Tujuan: kelola company, assignment module company, dan area per company

## Pola Implementasi

- Handler memakai mechanic.Error untuk semua error flow.
- Write endpoint memakai USLogs("SM03").
- List endpoint memakai ActionMeta (search, page, size, sort_by, sort_order).
- Parameter path wajib divalidasi di handler sebelum eksekusi usecase.

## Endpoint Aktif

- GET /rest/pages/SM03
- POST /rest/pages/SM03
- PUT /rest/pages/SM03/:id
- GET /rest/pages/SM03/module
- GET /rest/pages/SM03/:id/module
- GET /rest/pages/SM03/:id/module/select
- POST /rest/pages/SM03/:id/module
- PUT /rest/pages/SM03/:id/module/:moduleId
- GET /rest/pages/SM03/:id/area
- POST /rest/pages/SM03/:id/area
- PUT /rest/pages/SM03/:id/area/:areaId
- DELETE /rest/pages/SM03/:id/area/:areaId

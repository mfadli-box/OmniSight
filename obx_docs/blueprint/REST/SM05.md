# SM05 - Session Management API

## Ringkasan

- Route: /rest/pages/SM05
- Tujuan: list session aktif dan revoke session

## Technical Notes

- Read endpoint untuk list/detail session
- Write endpoint revoke memakai USLogs("SM05")
- Admin only

## Endpoint

- GET /rest/pages/SM05
- GET /rest/pages/SM05/:id
- DELETE /rest/pages/SM05/:id

## Checklist

- [ ] Session list tampil
- [ ] Detail session bisa dibuka
- [ ] Revoke aktif

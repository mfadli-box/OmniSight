# SM05 - Session Management API

## Ringkasan

- Route: `/rest/pages/SM05`
- Tujuan: melihat daftar session user, melihat detail session, dan mencabut session aktif
- Akses: group `admin` (`USAuth()` + `USLock()`)

## Technical Notes

- GET list mendukung `search`, `page`, `size`, `sort_by`, dan `sort_order`
- Query list menggabungkan `dat_user_session` dengan `dat_user`, serta mengambil company aktif pertama dari `dat_user_company`
- Detail mengembalikan token penuh, profil user, IP address, user agent, dan status session aktif
- DELETE revoke session menghapus row `dat_user_session` secara langsung
- Jika session tidak ditemukan saat revoke, API mengembalikan `NOT_FOUND`
- Write route revoke memakai `USLogs("SM05")`

## Endpoint

- `GET /rest/pages/SM05`
	- Response: paginated list session
- `GET /rest/pages/SM05/:id`
	- Response: satu object detail session
- `DELETE /rest/pages/SM05/:id`
	- Effect: mencabut session dengan menghapus token session dari database

## Sort dan Field Penting

- `sort_by` yang didukung: `username`, `created_at`, `expires_at`, `ip_address`
- List menampilkan `token_preview` sebagai 8 karakter awal token
- Field `is_active` dan `session_active` ditentukan dari `expires_at > NOW()`

# SM02 - Module Management API

## Ringkasan

- Prefix route: `/rest/pages/SM02`
- Scope: admin only (`USAuth()` + `USLock()`)
- Tujuan: list, create, dan update data module

## Pola Implementasi

- List mendukung query `search`, `page`, `size`, `sort_by`, `sort_order`.
- Endpoint select menyediakan list module aktif untuk kebutuhan relasi UI.
- Write endpoint (`POST`, `PUT`) memakai `USLogs("SM02")`.
- Update memvalidasi parameter path `id` di handler.

## Endpoint Aktif

- `GET /rest/pages/SM02` list module
- `GET /rest/pages/SM02/select` list module select
- `POST /rest/pages/SM02` create module
- `PUT /rest/pages/SM02/:id` update module

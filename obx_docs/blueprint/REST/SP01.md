# SP01 - Company Context

## Ringkasan

- Route: /rest/pages/SP01/company, /rest/pages/SP01/module, dan /rest/pages/SP01/privilege
- Tujuan: ambil company aktif, module list user, dan privilege user pada module aktif

## Technical Notes

- Menggunakan USLoad/USAuth context
- Menyediakan data company yang dipakai frontend sidebar
- Endpoint module dipakai untuk navigation/menu
- Endpoint privilege dipakai untuk menentukan level akses user terhadap module tertentu

## Endpoint

- GET /rest/pages/SP01/company
- GET /rest/pages/SP01/module
- GET /rest/pages/SP01/privilege

## Detail Endpoint

### GET /rest/pages/SP01/company

- Middleware: USAuth()
- Tujuan: mengambil daftar company aktif yang terasosiasi dengan session user
- Response utama: array `company_id` dan `name`

### GET /rest/pages/SP01/module

- Middleware: USAuth()
- Query: `company_id`
- Tujuan: mengambil tree module yang boleh diakses user pada company terpilih
- Catatan: jika `company_id` kosong maka response `data` berupa array kosong; admin menerima seluruh module aktif

### GET /rest/pages/SP01/privilege

- Middleware: USAuth()
- Sumber context:
	- `userId` dari session middleware
	- `companyId` dari header `X-Company-ID`
	- `moduleId` dari header/path context yang disuntik middleware
- Tujuan: mengambil level privilege user untuk module aktif
- Catatan: admin selalu menerima level `POST`
- Response utama: object `data.level`

# SP01 - Company Context

## Ringkasan

- Route: /rest/pages/SP01/company, /rest/pages/SP01/module, dan /rest/pages/SP01/privilege
- Tujuan: mengambil company user, tree module berdasar company, dan level privilege pada module aktif

## Technical Notes

- Scope endpoint: auth user (USAuth)
- Context session diambil dari middleware (userId, companyId, moduleId, isAdmin)
- Handler melakukan proteksi context session untuk mencegah panic type assertion
- Jika company_id tidak dikirim pada endpoint module, response data berupa array kosong
- Admin memperoleh tree module penuh (aktif), non-admin berdasarkan mapping privilege

## Endpoint

- GET /rest/pages/SP01/company
- GET /rest/pages/SP01/module?company_id={company_id}
- GET /rest/pages/SP01/privilege

## Response Utama

- company: data[] berisi company_id dan name
- module: data[] tree module
- privilege: data.level (HIDE, VIEW, BOOK, POST)

## Checklist Sinkronisasi

- [x] Company list valid sesuai session
- [x] Module list sesuai company context
- [x] Privilege level sesuai module aktif

# SP03 - Action History API

## Ringkasan

- Route: /rest/pages/SP03
- Tujuan: menampilkan riwayat aksi user login

## Technical Notes

- Scope endpoint: auth user (USAuth)
- User ID diambil dari context session middleware
- Mendukung query list melalui ActionMeta
- Response menyertakan data list dan meta pagination

## Endpoint

- GET /rest/pages/SP03

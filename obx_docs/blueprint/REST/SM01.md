# SM01 - User Management API

## Ringkasan

- Prefix route: `/rest/pages/SM01`
- Scope: admin only (`USAuth()` + `USLock()`)
- Tujuan: kelola user, assignment company, privilege modul, dan assignment area

## Pola Implementasi

- Handler menggunakan `mechanic.Error(c, err)` untuk semua error flow.
- Semua write endpoint memakai `USLogs("SM01")`.
- Query list memakai `ActionMeta` (search, page, size, sort_by, sort_order).
- Parameter path wajib divalidasi di handler sebelum eksekusi usecase.

## Endpoint Aktif

- `GET /rest/pages/SM01` list user
- `POST /rest/pages/SM01` create user
- `PUT /rest/pages/SM01/:id` update user
- `GET /rest/pages/SM01/hris` list referensi company HRIS
- `GET /rest/pages/SM01/company` list referensi company
- `GET /rest/pages/SM01/module` list referensi module
- `GET /rest/pages/SM01/area?company_id={id}` list area by company
- `GET /rest/pages/SM01/:id/company` list company assignment user
- `GET /rest/pages/SM01/:id/company/select` list company assignment untuk select privilege
- `POST /rest/pages/SM01/:id/company` assign company ke user
- `POST /rest/pages/SM01/:id/company/assign` create user-company relation
- `PUT /rest/pages/SM01/:id/company/:companyId` update status user-company
- `DELETE /rest/pages/SM01/:id/company/:companyId` delete user-company relation
- `GET /rest/pages/SM01/:id/privilege` list privilege user
- `POST /rest/pages/SM01/:id/privilege` create privilege user
- `PUT /rest/pages/SM01/:id/privilege/:privilegeId` update level privilege
- `DELETE /rest/pages/SM01/:id/privilege/:privilegeId` delete privilege
- `GET /rest/pages/SM01/:id/area` list area assignment user
- `POST /rest/pages/SM01/:id/area` create area assignment user
- `PUT /rest/pages/SM01/:id/area/:areaId` update status area assignment
- `DELETE /rest/pages/SM01/:id/area/:areaId` delete area assignment

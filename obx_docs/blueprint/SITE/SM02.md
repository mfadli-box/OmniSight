# SM02 - Module Management

## Ringkasan

- Route halaman: `/board/pages/SM02`
- Tujuan: mengelola data module (hierarki parent-child)
- Komponen utama: `DataTable`, `DataDialog`, `SearchSelect`, `Checkbox`

## Integrasi API (via proxy)

- `GET /proxy/pages/SM02` list module
- `GET /proxy/pages/SM02/select` list module select
- `POST /proxy/pages/SM02` create module
- `PUT /proxy/pages/SM02/:id` update module

## Pola UI yang Dipakai

- Tabel utama untuk list/sort/search/paging.
- Dialog create/update/detail menggunakan `react-hook-form` + `zod`.
- Parent module dipilih melalui `SearchSelect` dari endpoint select.
- Aturan flag:
	- jika tidak punya parent, `is_page` dipaksa `false`,
	- jika punya parent, `is_page` mengikuti input form.
- Semua write action memakai loading state `smLoading` untuk mencegah double submit.

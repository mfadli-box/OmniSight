# SP02 - Change Password

## Ringkasan

- Route: /board/pages/SP02
- Tujuan: user mengganti password akun sendiri
- Komponen utama: form react-hook-form, zod validation, toast, button loading

## Integrasi API via proxy

- PUT /proxy/pages/SP02

## Technical Notes

- Halaman membaca session dari local storage.
- Jika session invalid atau expired, user dipaksa logout.
- Field form: current_password, new_password, confirm_password.
- Validasi password menggunakan zod termasuk aturan kompleksitas.
- Akun HRIS tidak diizinkan mengubah password dari halaman ini.

# SP02 - Change Password

## Ringkasan

- Route: /board/pages/SP02
- Tujuan: user mengganti password akun sendiri
- Komponen utama: form sederhana, loading state, toast error

## Technical Notes

- Data source: /proxy/pages/SP02
- Request: password lama dan password baru
- Validasi memakai zod + react-hook-form
- Response error ditampilkan via getErrorMessage()

## UI Pattern

- Form input sederhana
- Write action wajib punya loading state
- Tidak memakai DataTable

## Checklist

- [ ] Validasi password lama dan baru aktif
- [ ] Loading state tampil saat submit
- [ ] Error 401/403 ditangani benar

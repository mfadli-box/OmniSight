# SM01 - User Management

## Ringkasan

- Route halaman: `/board/pages/SM01`
- Tujuan: admin mengelola user dan akses (company, privilege, area)
- Komponen utama: `DataTable`, `DataDialog`, `Tabs`, `SearchSelect`, `FieldError`

- `GET /proxy/pages/SM01`
- `POST /proxy/pages/SM01`
- `PUT /proxy/pages/SM01/:id`
- `GET /proxy/pages/SM01/hris`
- `GET /proxy/pages/SM01/company`
- `GET /proxy/pages/SM01/module`
- `GET /proxy/pages/SM01/area?company_id={id}`

## Pola UI yang Dipakai

- Tabel utama user untuk list/sort/search/paging.
- `DataDialog` mode create/update/detail untuk data user.
- Mode detail memakai `Tabs`: information, company, privilege, area.
- Form memakai `react-hook-form` + `zod` + komponen `FieldError`.
- Error API memakai `toast.error(getErrorMessage(code))`.
- Write action memakai loading state terpisah: user/company/privilege/area.

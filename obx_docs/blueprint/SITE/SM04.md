# SM04 - Signature Type

## Ringkasan

- Route: `/board/pages/SM04`
- Tujuan: mengelola signature type dan approval signer untuk workflow dokumen
- Komponen utama: `DataTable`, `DataDialog`, `useFieldArray`, `Select`, pencarian signer manual

## Technical Notes

- Data source utama: `/proxy/pages/SM04`
- Lookup signer: `/proxy/pages/SM04/user`
- Form create dan update memakai satu schema `steps[]` dengan `step`, `condition`, dan `user_ids[]`
- Step signer dapat ditambah dan dihapus dinamis via `useFieldArray`
- Search signer memakai debounce 300ms dan menyimpan hasil ke `searchResults`
- Detail dialog menampilkan `code`, `name`, `created_at`, lalu daftar approval step dan signer per step

## UI Pattern

- `DataTable` untuk list signature type
- `DataDialog` untuk create, update, dan detail
- Step array dirender sebagai kumpulan blok form bertingkat
- Signer picker menggunakan hasil pencarian user aktif, bukan combobox statis

# SM03 - Company Management

## Ringkasan

- Route halaman: /board/pages/SM03
- Tujuan: admin mengelola company beserta module assignment dan area
- Komponen utama: DataTable, DataDialog, Tabs, SearchSelect, FieldError

## Integrasi API via proxy

- GET /proxy/pages/SM03
- POST /proxy/pages/SM03
- PUT /proxy/pages/SM03/:id
- GET /proxy/pages/SM03/module
- GET /proxy/pages/SM03/:id/module
- GET /proxy/pages/SM03/:id/module/select
- POST /proxy/pages/SM03/:id/module
- PUT /proxy/pages/SM03/:id/module/:moduleId
- GET /proxy/pages/SM03/:id/area
- POST /proxy/pages/SM03/:id/area
- PUT /proxy/pages/SM03/:id/area/:areaId
- DELETE /proxy/pages/SM03/:id/area/:areaId

## Pola UI yang Dipakai

- Tabel utama company untuk list/sort/search/paging.
- Dialog detail berisi tab Information, Modules, dan Areas.
- Form create/update memakai react-hook-form + zod.
- Assignment module memakai SearchSelect dengan filter module yang belum di-assign.
- Semua write action memakai loading state terpisah: company, module, area.

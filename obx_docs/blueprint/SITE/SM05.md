s# SM05 - Session Management

## Ringkasan

- Route: `/board/pages/SM05`
- Tujuan: melihat daftar session user, membuka detail session, dan revoke session
- Komponen utama: `DataTable`, `DataDialog`, aksi detail, aksi revoke

## Technical Notes

- Data source: `/proxy/pages/SM05`
- Detail data source: `/proxy/pages/SM05/:id`
- Revoke action: `DELETE /proxy/pages/SM05/:id`
- Kolom utama list: username, fullname, company, IP address, token preview, created, expires, status
- Detail dialog membagi informasi menjadi `User Information` dan `Session Information`
- Token penuh hanya tampil pada detail dialog

## UI Pattern

- `DataTable` untuk list session dengan search, sort, dan pagination
- `DataDialog` detail untuk inspeksi token dan metadata session
- Aksi revoke tersedia langsung dari row table

## Checklist

- [x] List session tampil
- [x] Detail session bisa dibuka
- [x] Revoke session berjalan

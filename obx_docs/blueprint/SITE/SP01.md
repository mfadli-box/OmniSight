# SP01 - Profile / Company Context

## Ringkasan

- Route: /board/pages/SP01
- Tujuan: melihat profile user, company aktif, dan context session
- Komponen utama: SearchSelect, DataTable, DataDialog

## Technical Notes

- Data source: /proxy/pages/SP01/company, /proxy/pages/SP01/module
- Fetch memakai clientApi()
- Session validasi bergantung pada cookie/localStorage OmniSightMemory
- Halaman ini membaca company context dari sidebar dan session login

## UI Pattern

- Profile summary ditampilkan di layout/page utama
- Company list memakai SearchSelect
- Data referensi memakai DataTable bila perlu list detail

## Interaksi

- User dapat berpindah company context sesuai akses
- Jika session tidak valid, proxy akan redirect ke /login

## Validation

- Pastikan company list muncul setelah login
- Pastikan company context tersimpan ke localStorage

# SP01 - Profile and Session Context

## Ringkasan

- Route: /board/pages/SP01
- Tujuan: menampilkan profil user login dan informasi session aktif
- Komponen utama: Tabs, Field, Input, Badge

## Technical Notes

- Halaman membaca data dari session local storage, bukan fetch endpoint langsung
- Jika session tidak ada atau expired, halaman melakukan force logout ke login
- Field profil sensitif tertentu disembunyikan dari tampilan
- Status akun ditampilkan sebagai badge

## UI Pattern

- Halaman read-only berbasis form layout
- Tidak ada aksi create, update, atau delete
- Tidak menggunakan DataTable

## Checklist Sinkronisasi

- [x] Profile fields tampil read-only
- [x] Token dan expiry tampil di panel session
- [x] Session invalid diarahkan ke login

# BOARD - Panduan Dashboard Shell

## Ringkasan Fitur

Halaman ini adalah shell utama setelah login.

## Prasyarat Akses

- Session login aktif

## Langkah Penggunaan

1. Login ke aplikasi.
2. Masuk ke halaman /board.
3. Gunakan sidebar untuk berpindah halaman.

## Validasi Hasil

- Sidebar dan breadcrumb tampil.
- Akses halaman modul berjalan.

## Troubleshooting

- Jika diarahkan ke login, session mungkin expired.

# SM04 - Panduan Signature Type

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengatur signature type, urutan approval step, dan signer per step.

## Prasyarat Akses

- User admin

## Langkah Penggunaan

1. Buka menu `Signature`.
2. Tekan tombol tambah untuk membuat signature type baru.
3. Isi `Code` dan `Name`.
4. Tambahkan satu atau lebih approval step.
5. Tentukan `Condition` tiap step: semua signer wajib approve atau salah satu signer cukup approve.
6. Cari dan pilih signer aktif untuk tiap step.
7. Simpan form.

## Validasi Hasil

- Record baru muncul pada list signature type.
- Jumlah step tampil benar pada kolom `Steps`.
- Detail signature type menampilkan signer per step secara lengkap.

## Troubleshooting

- Jika form gagal disimpan, pastikan `Code` dan `Name` terisi.
- Jika step tidak valid, pastikan minimal ada satu signer pada step terkait.

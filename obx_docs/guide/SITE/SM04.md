# SM04 - Panduan Signature Type

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengatur tipe approval dan step signer.

## Prasyarat Akses

- User admin

## Langkah Penggunaan

1. Buka menu Signature Type.
2. Tambah tipe approval baru.
3. Atur step dan signer.
4. Simpan perubahan.

## Validasi Hasil

- Tipe approval dan step tampil sesuai konfigurasi.

## Troubleshooting

- Jika step tidak tersimpan, cek signer minimal satu user.

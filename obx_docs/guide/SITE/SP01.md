# SP01 - Panduan Profile and Session Context

## Ringkasan Fitur

Halaman SP01 dipakai user untuk melihat informasi profil dan status session yang sedang aktif.

## Prasyarat Akses

- User sudah login

## Langkah Penggunaan

1. Buka menu Profile pada route /board/pages/SP01.
2. Tinjau informasi profil yang ditampilkan.
3. Periksa token dan waktu kedaluwarsa session.
4. Gunakan informasi status untuk memastikan akun aktif sesuai kebutuhan.

## Validasi Hasil

- Data profil terbaca sesuai session login.
- Token dan expired timestamp tampil.
- Jika session tidak valid, user diarahkan kembali ke login.

## Troubleshooting

- Jika halaman kosong, lakukan login ulang.
- Jika data profil tidak sesuai, pastikan session yang tersimpan adalah session terbaru.

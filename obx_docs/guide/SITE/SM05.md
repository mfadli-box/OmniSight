# SM05 - Panduan Session Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk melihat dan mencabut session aktif.

## Prasyarat Akses

- User admin

## Langkah Penggunaan

1. Buka menu Session Management.
2. Cari session yang ingin diperiksa.
3. Buka detail jika perlu.
4. Cabut session bila diperlukan.

## Validasi Hasil

- Session yang dicabut tidak bisa dipakai lagi.

## Troubleshooting

- Jika revoke gagal, cek privilege admin dan status session.

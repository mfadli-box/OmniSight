# SM05 - Panduan Session Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk melihat session user yang aktif, meninjau detailnya, dan mencabut session tertentu.

## Prasyarat Akses

- User admin

## Langkah Penggunaan

1. Buka menu `Session`.
2. Gunakan search bila ingin menemukan session berdasarkan user atau IP address.
3. Buka detail session untuk melihat token, user agent, dan waktu kadaluwarsa.
4. Gunakan aksi revoke jika session harus dicabut.

## Validasi Hasil

- Session tampil pada list dengan status aktif atau expired.
- Detail session menampilkan metadata lengkap.
- Session yang direvoke tidak lagi dapat digunakan.

## Troubleshooting

- Jika detail tidak muncul, pastikan session ID masih valid.
- Jika revoke gagal, cek privilege admin dan konektivitas backend.

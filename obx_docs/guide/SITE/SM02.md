# SM02 - Panduan Module Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengelola modul aplikasi.

## Prasyarat Akses

- User admin

## Langkah Penggunaan

1. Buka menu Module Management.
2. Tambah atau ubah modul.
3. Simpan perubahan.

## Validasi Hasil

- Modul tampil di daftar.
- Data modul bisa dipakai halaman lain.

## Troubleshooting

- Jika modul tidak muncul, cek akses admin dan data backend.

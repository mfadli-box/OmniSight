# SM02 - Panduan Module Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengelola modul aplikasi, termasuk modul induk dan turunan.

## Prasyarat Akses

- User login dengan hak admin.

## Langkah Penggunaan

1. Buka menu Module Management (`/board/pages/SM02`).
2. Klik Create untuk menambah modul baru.
3. Opsional: pilih Parent Module jika modul merupakan turunan.
4. Isi `code`, `name`, `path`, lalu simpan.
5. Gunakan Update untuk mengubah data modul yang sudah ada.

## Validasi Hasil

- Modul tampil pada tabel utama.
- Modul parent tersedia sebagai opsi pada form create/update.
- Perubahan status active dan flag page tercermin di daftar.

## Troubleshooting

- Jika simpan gagal, cek field wajib (`code`, `name`, `path`).
- Jika parent tidak muncul, pastikan parent aktif dan endpoint select tersedia.
- Jika halaman kosong, cek session login admin masih valid.

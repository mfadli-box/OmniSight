# LOGIN - Panduan Authentication Page

## Ringkasan Fitur

Halaman ini dipakai untuk masuk ke aplikasi.

## Prasyarat Akses

- Company, username, dan password valid

## Langkah Penggunaan

1. Buka halaman login.
2. Pilih company bila perlu.
3. Isi username, password, dan captcha.
4. Klik sign in.

## Validasi Hasil

- User diarahkan ke /board.
- Session tersimpan di browser.

## Troubleshooting

- Jika gagal login, cek company, password, dan captcha.

# SM01 - Panduan User Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengelola user dan aksesnya.

## Prasyarat Akses

- User admin
- Company, module, dan area referensi tersedia

## Langkah Penggunaan

1. Buka menu User Management.
2. Tambah atau ubah user.
3. Atur company, privilege, dan area bila diperlukan.
4. Simpan perubahan.

## Validasi Hasil

- User tampil di daftar.
- Hak akses user sesuai setting.

## Troubleshooting

- Jika data tidak bisa disimpan, cek field wajib dan referensi company/module/area.

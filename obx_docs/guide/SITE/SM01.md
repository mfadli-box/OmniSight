# SM01 - Panduan User Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengelola user dan pengaturan aksesnya dalam satu dialog detail berbasis tab.

## Prasyarat Akses

- User login dengan role admin.
- Data company, module, dan area sudah tersedia.

## Langkah Penggunaan

1. Buka menu User Management (`/board/pages/SM01`).
2. Klik Create untuk menambah user baru, lalu isi field wajib (username, email, password, fullname).
3. Klik Detail pada user untuk mengatur:
	- tab Company: relasi user-company,
	- tab Privilege: level module (`HIDE`, `VIEW`, `BOOK`, `POST`),
	- tab Area: relasi user-area per company.
4. Gunakan Update untuk mengubah data profil user.

## Validasi Hasil

- User baru muncul di tabel utama.
- Assignment company/privilege/area tampil pada tab yang sesuai.
- Status active/inactive tercermin setelah update.

## Troubleshooting

- Jika gagal simpan, periksa pesan validasi field dari form.
- Jika data referensi kosong, cek endpoint referensi (`/SM01/company`, `/SM01/module`, `/SM01/area`).
- Jika akses ditolak, pastikan session pengguna memiliki hak admin.

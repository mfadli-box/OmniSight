# SP03 - Panduan Action History

## Ringkasan Fitur

Halaman ini dipakai user untuk melihat riwayat aktivitas akunnya.

## Prasyarat Akses

- User login aktif

## Langkah Penggunaan

1. Buka route /board/pages/SP03.
2. Gunakan search jika ingin memfilter aksi tertentu.
3. Klik detail untuk melihat informasi path, IP, user agent, dan waktu.

## Validasi Hasil

- Data aktivitas tampil pada tabel.
- Informasi detail tampil pada dialog.

## Troubleshooting

- Jika data kosong, kemungkinan belum ada aktivitas tercatat.
- Jika gagal memuat data, cek session login dan koneksi backend.

# SP03 - Panduan Action History

## Ringkasan Fitur

Halaman ini dipakai untuk melihat riwayat aktivitas user.

## Prasyarat Akses

- Session login aktif

## Langkah Penggunaan

1. Buka menu History.
2. Gunakan search atau pagination bila data banyak.
3. Baca daftar aksi yang tampil.

## Validasi Hasil

- Riwayat aksi tampil sesuai user aktif.

## Troubleshooting

- Jika data kosong, cek apakah user pernah melakukan aksi.

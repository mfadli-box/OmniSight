# SP02 - Panduan Change Password

## Ringkasan Fitur

Halaman ini dipakai user non-HRIS untuk mengganti password akun sendiri.

## Prasyarat Akses

- User login aktif
- User mengetahui password lama

## Langkah Penggunaan

1. Buka route /board/pages/SP02.
2. Isi current password.
3. Isi new password dan konfirmasi password baru.
4. Kirim form perubahan password.

## Validasi Hasil

- Muncul notifikasi sukses setelah update.
- Form kembali kosong setelah berhasil.

## Troubleshooting

- Jika password tidak cocok, periksa field konfirmasi.
- Jika ditolak, cek session masih aktif.
- Jika akun HRIS, perubahan password tidak tersedia di halaman ini.

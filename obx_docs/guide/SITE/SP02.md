# SP02 - Panduan Change Password

## Ringkasan Fitur

Halaman ini dipakai untuk mengganti password akun user.

## Prasyarat Akses

- Session login aktif
- User tahu password lama

## Langkah Penggunaan

1. Buka menu Password.
2. Isi password lama.
3. Isi password baru.
4. Konfirmasi perubahan.

## Validasi Hasil

- Password berhasil diperbarui.
- User tetap bisa login dengan password baru.

## Troubleshooting

- Jika gagal, cek password lama dan aturan password baru.

# SM03 - Panduan Company Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengelola company dan relasinya.

## Prasyarat Akses

- User admin

## Langkah Penggunaan

1. Buka menu Company Management.
2. Tambah atau ubah company.
3. Atur module dan area jika diperlukan.
4. Simpan perubahan.

## Validasi Hasil

- Company dan relasinya tampil benar.

## Troubleshooting

- Jika relasi gagal disimpan, cek data referensi dan privilege.

# SM03 - Panduan Company Management

## Ringkasan Fitur

Halaman ini dipakai admin untuk mengelola company dan dua relasi utama: module assignment dan area.

## Prasyarat Akses

- User login dengan hak admin.

## Langkah Penggunaan

1. Buka menu Company Management pada route /board/pages/SM03.
2. Gunakan Create untuk menambah company baru, atau Update untuk mengubah data company.
3. Buka Detail company lalu:
	- tab Modules untuk assign atau ubah status module,
	- tab Areas untuk tambah, ubah, atau hapus area.
4. Simpan perubahan pada setiap dialog tindakan.

## Validasi Hasil

- Company tampil di tabel utama dengan status yang benar.
- Module yang dipilih muncul di daftar module company.
- Data area bertambah atau berubah sesuai operasi.

## Troubleshooting

- Jika data gagal disimpan, cek field wajib pada form.
- Jika module tidak tersedia, cek endpoint list module pada backend.
- Jika akses ditolak, validasi kembali session admin aktif.

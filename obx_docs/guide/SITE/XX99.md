# XX99 - Panduan Template Page (SITE)

## Ringkasan

Halaman XX99 adalah template CRUD di frontend untuk referensi pengembangan halaman baru.

## Route

- Frontend: `/board/pages/XX99`
- Source page: `obx_site/src/app/board/pages/XX99/page.tsx`

## Pola Penggunaan

1. Buka halaman XX99 dari board.
2. Gunakan search/sort/pagination pada DataTable.
3. Gunakan tombol create/update/detail/delete untuk operasi data.

## Catatan Penting

- Halaman frontend tersedia di source code.
- Integrasi penuh membutuhkan route backend XX99 aktif.
- Jika route backend belum aktif, request API XX99 akan gagal.

## Validasi

- UI halaman dapat dirender tanpa crash.
- Dialog create/update/detail dapat dibuka.
- CRUD end-to-end hanya valid jika backend route XX99 sudah diregistrasi.

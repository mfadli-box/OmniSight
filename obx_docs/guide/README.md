# User Guide Dokumentasi

Folder ini berisi dokumentasi user guide per submodul dengan pola wajib:

- obx_docs/guide/{SUBMODUL}.md

## Tujuan

- Menjelaskan penggunaan fitur dari sisi pengguna akhir.
- Menjadi referensi onboarding dan operasi harian.
- Melengkapi blueprint teknis dengan panduan langkah penggunaan.

## Struktur Standar

Setiap user guide minimal memiliki bagian berikut:

1. Ringkasan Fitur
2. Prasyarat Akses
3. Langkah Penggunaan
4. Validasi Hasil
5. Troubleshooting

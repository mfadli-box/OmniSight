# SM01 - Panduan User Management API

## Ringkasan Fitur

API ini dipakai untuk pengelolaan user, company assignment, privilege, dan area.

## Prasyarat Akses

- Token admin aktif

## Langkah Penggunaan

1. Panggil endpoint list user.
2. Tambah atau ubah user.
3. Atur company, privilege, atau area bila diperlukan.

## Validasi Hasil

- Perubahan tersimpan dan tercatat di audit log.

## Troubleshooting

- Jika ditolak, cek privilege admin.

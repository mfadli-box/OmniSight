# SM01 - Panduan User Management API

## Ringkasan Fitur

API SM01 dipakai admin untuk:

- membuat dan memperbarui user,
- mengaitkan user ke company,
- mengatur level privilege module,
- mengatur assignment area per company.

## Prasyarat Akses

- Session token admin valid.
- Data master company, module, dan area sudah tersedia.

## Alur Penggunaan Rekomendasi

1. Ambil daftar user lewat `GET /rest/pages/SM01`.
2. Tambah user lewat `POST /rest/pages/SM01` atau ubah lewat `PUT /rest/pages/SM01/:id`.
3. Tambah company assignment user lewat `POST /rest/pages/SM01/:id/company` atau `POST /rest/pages/SM01/:id/company/assign`.
4. Ambil company assignment (`GET /rest/pages/SM01/:id/company/select`) lalu buat privilege (`POST /rest/pages/SM01/:id/privilege`).
5. Tambah area assignment lewat `POST /rest/pages/SM01/:id/area`.

## Validasi Hasil

- Perubahan data terlihat pada endpoint list terkait.
- Update/delete relation tercermin pada list relation terkait.
- Operasi write tercatat melalui middleware log modul SM01.

## Troubleshooting

- Jika respons `FORBIDDEN`, pastikan user adalah admin.
- Jika respons `VALIDATION_ERROR`, cek parameter path (`id`, `companyId`, `privilegeId`, `areaId`) dan field body wajib.
- Jika data area kosong, pastikan `company_id` dikirim saat memanggil `GET /rest/pages/SM01/area`.

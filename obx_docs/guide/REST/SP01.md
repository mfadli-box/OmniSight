# SP01 - Panduan Company Context

## Ringkasan Fitur

Endpoint SP01 dipakai untuk mengambil company aktif, daftar module, dan level privilege user pada module yang sedang diakses.

## Prasyarat Akses

- Session login aktif
- Header `X-Company-ID` tersedia saat mengecek privilege module

## Langkah Penggunaan

1. Panggil `GET /rest/pages/SP01/company` untuk mengambil daftar company yang tersedia bagi user login.
2. Pilih salah satu `company_id`, lalu panggil `GET /rest/pages/SP01/module?company_id={company_id}` untuk memuat tree module.
3. Saat perlu mengecek hak akses halaman aktif, panggil `GET /rest/pages/SP01/privilege` dengan company context yang sama.
4. Pastikan nilai `data.level` sesuai module yang sedang dibuka.

## Daftar Endpoint

- `GET /rest/pages/SP01/company`: daftar company user
- `GET /rest/pages/SP01/module?company_id={company_id}`: tree module berdasarkan company
- `GET /rest/pages/SP01/privilege`: level privilege untuk module aktif

## Validasi Hasil

- Company tampil sesuai session.
- Module tampil sesuai company terpilih.
- Privilege mengembalikan level seperti `VIEW` atau `POST` sesuai akses user.

## Troubleshooting

- Jika daftar company kosong, cek session login dan relasi user-company.
- Jika module kosong, pastikan `company_id` dikirim dan user punya privilege aktif.
- Jika privilege tidak sesuai, cek header `X-Company-ID`, context module, dan mapping `dat_user_privilege`.

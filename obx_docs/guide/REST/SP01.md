# SP01 - Panduan Company Context

## Ringkasan Fitur

Endpoint SP01 dipakai frontend untuk memuat company yang bisa diakses user, daftar module untuk company aktif, dan level privilege halaman aktif.

## Prasyarat Akses

- Session login aktif
- company_id dikirim saat memuat module

## Langkah Penggunaan

1. Panggil GET /rest/pages/SP01/company untuk memuat daftar company user.
2. Pilih company_id, lalu panggil GET /rest/pages/SP01/module?company_id={company_id}.
3. Saat perlu cek hak akses halaman, panggil GET /rest/pages/SP01/privilege.
4. Gunakan data.level untuk menentukan aksi UI yang boleh diakses.

## Validasi Hasil

- Daftar company tampil sesuai relasi user-company.
- Tree module tampil sesuai akses user dan company aktif.
- Privilege level terbaca konsisten terhadap module aktif.

## Troubleshooting

- Jika company kosong, cek relasi user-company.
- Jika module kosong, pastikan company_id dikirim dan valid.
- Jika privilege tidak sesuai, cek mapping dat_user_privilege pada company aktif.

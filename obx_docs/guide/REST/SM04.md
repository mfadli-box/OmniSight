# SM04 - Panduan Signature Type API

## Ringkasan Fitur

API ini dipakai untuk mengelola tipe approval dan user signer.

## Prasyarat Akses

- Token admin aktif

## Langkah Penggunaan

1. Ambil daftar signature type.
2. Tambah atau ubah tipe approval.
3. Lihat daftar user signer jika diperlukan.

## Validasi Hasil

- Tipe approval tersimpan dengan benar.

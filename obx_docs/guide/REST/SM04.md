# SM04 - Panduan Signature Type API

## Ringkasan Fitur

API ini dipakai admin untuk mengelola tipe approval dokumen berbasis beberapa step dan signer.

## Prasyarat Akses

- Token admin aktif

## Langkah Penggunaan

1. Panggil `GET /rest/pages/SM04` untuk melihat daftar signature type.
2. Siapkan payload create atau update dengan `code`, `name`, dan `steps`.
3. Untuk setiap step, tentukan urutan `step`, `condition`, dan daftar `user_ids` signer.
4. Gunakan `GET /rest/pages/SM04/user?search=...` untuk mencari user signer aktif.
5. Simpan perubahan via `POST /rest/pages/SM04` atau `PUT /rest/pages/SM04/:id`.

## Validasi Hasil

- Signature type tampil kembali di list setelah disimpan.
- Approval step tersusun sesuai urutan step.
- Signer per step tersimpan dan dapat ditampilkan ulang pada detail.

# SP03 - Panduan Action History

## Ringkasan Fitur

Halaman ini menampilkan riwayat aksi user.

## Prasyarat Akses

- Session login aktif

## Langkah Penggunaan

1. Buka halaman history.
2. Gunakan search bila diperlukan.
3. Baca daftar aksi.

## Validasi Hasil

- Riwayat aksi tampil sesuai user aktif.

## Troubleshooting

- Jika kosong, cek apakah user sudah melakukan aksi.

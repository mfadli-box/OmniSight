# SP03 - Panduan Action History API

## Ringkasan Fitur

Endpoint ini menampilkan riwayat aksi user yang sedang login untuk kebutuhan audit ringan.

## Prasyarat Akses

- Session login aktif

## Langkah Penggunaan

1. Panggil GET /rest/pages/SP03.
2. Gunakan parameter search, page, size, sort_by, dan sort_order bila diperlukan.
3. Tampilkan data aksi beserta waktu kejadian.

## Validasi Hasil

- Data aksi hanya untuk user login saat ini.
- Meta pagination sesuai jumlah data.

## Troubleshooting

- Jika data kosong, pastikan user sudah memiliki riwayat aksi.
- Jika request ditolak, cek session token masih valid.

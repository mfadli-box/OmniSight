# SM02 - Panduan Module Management API

## Ringkasan Fitur

API SM02 dipakai admin untuk mengelola struktur modul aplikasi dan menyediakan data select untuk halaman lain.

## Prasyarat Akses

- Session token admin valid.

## Langkah Penggunaan

1. Ambil data modul dengan `GET /rest/pages/SM02`.
2. Buat modul baru dengan `POST /rest/pages/SM02`.
3. Ubah modul dengan `PUT /rest/pages/SM02/:id`.
4. Untuk dropdown relasi, ambil opsi dengan `GET /rest/pages/SM02/select`.

## Validasi Hasil

- Modul tampil pada daftar.
- Perubahan modul bisa dipakai pada assignment privilege atau relasi modul lain.

## Troubleshooting

- Jika gagal simpan, cek field wajib: `code`, `name`, `path`.
- Jika update gagal validasi, cek parameter `:id` pada route.
- Jika akses ditolak, pastikan akun memiliki hak admin.

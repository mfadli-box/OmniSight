# SM02 - Panduan Module Management API

## Ringkasan Fitur

API ini dipakai untuk mengelola module aplikasi.

## Prasyarat Akses

- Token admin aktif

## Langkah Penggunaan

1. Ambil daftar module.
2. Tambah atau ubah module.
3. Gunakan select endpoint bila perlu.

## Validasi Hasil

- Module tampil dan dapat dipakai relation lain.

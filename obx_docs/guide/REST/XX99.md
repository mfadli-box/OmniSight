# XX99 - Panduan Template Module Autopilot

## Ringkasan Fitur

Halaman XX99 adalah contoh modul daftar data untuk alur autopilot implementasi modul baru.

Status saat ini: endpoint backend XX99 belum diregistrasi pada `obx_rest/backbone/routes.go`.

## Prasyarat Akses

- User memiliki akses privilege XX99
- User sudah login dan memiliki Authorization token valid
- Context company aktif jika dibutuhkan oleh data scope
- Route XX99 sudah diaktifkan di backend (wajib untuk uji end-to-end)

## Langkah Penggunaan

1. Buka halaman XX99 dari board.
2. Lihat daftar data pada tabel utama.
3. Klik tambah untuk membuka dialog input.
4. Isi field wajib (company, code, name, status aktif) lalu simpan.
5. Gunakan aksi edit atau delete pada baris data untuk pemeliharaan data.

## Validasi Hasil

- Data baru tampil di tabel setelah simpan.
- Detail data dapat dibuka menggunakan id.
- Update dan delete memunculkan hasil sesuai aksi.

## Troubleshooting

- 401 Unauthorized: lakukan login ulang lalu ulangi request.
- 403 Forbidden: cek privilege XX99 pada akun.
- Gagal simpan: pastikan field wajib terisi dan code unik.
- Data tidak muncul: cek filter, pagination, dan context company.

## Smoke Test API (Token Valid)

1. Login melalui endpoint guest dan ambil token Authorization.
2. Panggil GET `/rest/pages/XX99` dengan header Bearer token.
3. Uji POST data contoh:
	- company_id: id company valid
	- code: XX99-SMOKE-001
	- name: XX99 Smoke Data
	- is_active: true
4. Uji PUT ke id yang dibuat, lalu verifikasi perubahan.
5. Uji DELETE ke id yang sama, lalu pastikan data hilang dari list.

Catatan:

- Seed XX99 otomatis dibuat saat `prisma db seed` jika minimal satu data company tersedia.
- Jika route belum aktif, data seed XX99 tidak dapat diakses melalui endpoint `/rest/pages/XX99`.

# SM05 - Panduan Session Management API

## Ringkasan Fitur

API ini dipakai admin untuk memonitor session user dan mencabut session yang tidak lagi diizinkan.

## Prasyarat Akses

- Token admin aktif

## Langkah Penggunaan

1. Panggil `GET /rest/pages/SM05` untuk mengambil daftar session.
2. Gunakan parameter `search` bila ingin memfilter berdasarkan username, fullname, atau IP address.
3. Panggil `GET /rest/pages/SM05/:id` untuk melihat detail session tertentu.
4. Panggil `DELETE /rest/pages/SM05/:id` untuk mencabut session.

## Validasi Hasil

- Session yang dicabut hilang dari daftar aktif.
- Detail session menampilkan user, token, IP, user agent, dan masa berlaku.

## Troubleshooting

- Jika revoke gagal, cek privilege admin.
- Jika session tidak ditemukan, cek apakah token sudah kadaluwarsa atau sudah pernah dicabut.

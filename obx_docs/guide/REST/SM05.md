# SM05 - Panduan Session Management API

## Ringkasan Fitur

API ini dipakai untuk melihat dan mencabut session aktif.

## Prasyarat Akses

- Token admin aktif

## Langkah Penggunaan

1. Lihat daftar session.
2. Buka detail session bila perlu.
3. Cabut session yang tidak diperlukan.

## Validasi Hasil

- Session yang dicabut tidak lagi aktif.

## Troubleshooting

- Jika revoke gagal, cek privilege admin.

# SM03 - Panduan Company Management API

## Ringkasan Fitur

API SM03 dipakai admin untuk mengelola data company dan relasi operasionalnya (module dan area).

## Prasyarat Akses

- Session token admin valid.

## Alur Penggunaan Rekomendasi

1. Ambil daftar company dengan GET /rest/pages/SM03.
2. Tambah company dengan POST /rest/pages/SM03 atau ubah dengan PUT /rest/pages/SM03/:id.
3. Kelola assignment module company melalui endpoint /rest/pages/SM03/:id/module.
4. Kelola area company melalui endpoint /rest/pages/SM03/:id/area.

## Validasi Hasil

- Data company tampil dan berubah sesuai operasi.
- Daftar module assignment mencerminkan relasi aktif.
- Daftar area per company sinkron setelah create/update/delete.

## Troubleshooting

- Jika respons VALIDATION_ERROR, cek parameter path id, moduleId, atau areaId.
- Jika module tidak bisa di-assign, cek ketersediaan module aktif dari GET /rest/pages/SM03/module.
- Jika akses ditolak, pastikan akun memiliki hak admin.

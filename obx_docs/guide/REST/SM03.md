# SM03 - Panduan Company Management API

## Ringkasan Fitur

API ini dipakai untuk mengelola company serta relasinya.

## Prasyarat Akses

- Token admin aktif

## Langkah Penggunaan

1. Ambil daftar company.
2. Tambah atau ubah company.
3. Atur module dan area bila diperlukan.

## Validasi Hasil

- Company dan relasinya tersimpan.

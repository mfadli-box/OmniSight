# SP00 - Panduan Guest Auth Flow

## Ringkasan Fitur

Halaman ini digunakan untuk login dan logout awal.

## Prasyarat Akses

- Company dan user valid
- Session belum expired

## Langkah Penggunaan

1. Ambil daftar company HRIS.
2. Login dengan username dan password.
3. Simpan token session.
4. Logout bila selesai.

## Validasi Hasil

- Token session tersimpan.
- User bisa masuk ke /rest/pages.

## Troubleshooting

- Jika login gagal, cek company/username/password.

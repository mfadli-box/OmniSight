# SP02 - Panduan Change Password API

## Ringkasan Fitur

Endpoint ini dipakai user login untuk mengganti password akun sendiri.

## Prasyarat Akses

- Session login aktif
- User mengetahui password saat ini

## Langkah Penggunaan

1. Kirim PUT /rest/pages/SP02.
2. Sertakan current_password dan new_password pada body.
3. Jika berhasil, sistem mengembalikan pesan perubahan password sukses.

## Validasi Hasil

- Password baru dapat dipakai untuk login berikutnya.
- Password lama tidak berlaku lagi.

## Troubleshooting

- Jika gagal, cek current_password benar.
- Pastikan format new_password mengikuti aturan minimal keamanan frontend.

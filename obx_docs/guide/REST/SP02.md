# SP02 - Panduan Change Password

## Ringkasan Fitur

Halaman ini dipakai untuk mengganti password user aktif.

## Prasyarat Akses

- Session login aktif

## Langkah Penggunaan

1. Buka menu change password.
2. Isi password lama dan baru.
3. Simpan perubahan.

## Validasi Hasil

- Password user berhasil diganti.

## Troubleshooting

- Jika gagal, cek password lama dan aturan password baru.

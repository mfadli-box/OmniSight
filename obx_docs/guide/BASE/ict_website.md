# ict_website - Panduan Website Infra Domain

## Ringkasan Fitur

Schema ini dipakai untuk operasional website, log, SSL, dan SLA.

## Langkah Penggunaan

1. Perbarui schema saat menambah kebutuhan log atau SSL.
2. Sinkronkan dengan agent_ws dan dokumen backend.

## Validasi Hasil

- Log website tetap tersimpan.
- SLA dan SSL tetap konsisten.

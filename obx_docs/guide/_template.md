## Langkah Penggunaan

1. Buka menu {KODE} dari board.
2. Gunakan pencarian/filter untuk menemukan data.
3. Klik tambah untuk membuat data baru.
4. Isi form sesuai field wajib.
5. Simpan lalu verifikasi data muncul pada daftar.

## Validasi Hasil

- Data tampil pada tabel/list.
- Detail menampilkan field yang benar.
- Perubahan data tersimpan.
- Penghapusan data tercatat.

## Troubleshooting

- Jika gagal simpan, cek field wajib dan format input.
- Jika data tidak muncul, cek filter aktif.
- Jika akses ditolak, konfirmasi privilege dengan admin.

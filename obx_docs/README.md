# obx_docs

Pusat dokumentasi proyek yang dibagi menjadi dua jalur utama:

- `obx_docs/blueprint/` untuk dokumentasi teknis per submodul
- `obx_docs/guide/` untuk dokumentasi user guide per submodul
- `obx_docs/autopilot/` untuk dokumen operasional pembuatan modul oleh AI

## Konvensi Path

- Teknis: `obx_docs/blueprint/{SUBMODUL}/README.md`
- User guide: `obx_docs/guide/{SUBMODUL}.md`

## Entry Point

- Lihat indeks teknis di `obx_docs/blueprint/README.md`
- Lihat indeks user guide di `obx_docs/guide/README.md`
- Lihat runbook AI di `obx_docs/autopilot/README.md`

## Template

- Template blueprint: `obx_docs/blueprint/_template/README.md`
- Template guide: `obx_docs/guide/_template.md`
